# Firefox Theme

**Mocha Fox** — Minimalist Catppuccin Mocha theme for Firefox 154+.

## Files

- `Colors.css` — Catppuccin Mocha palette + semantic variables
- `userChrome.css` — Layout: vertical sidebar, thin launcher, peek bookmarks
- `userContent.css` — About:blank/newtab background

## Design

- **Sidebar**: Nova vertical tabs, collapsed to 48px icon strip
- **Tabs**: favicon-only when collapsed, labels appear when expanded
- **Bookmarks**: always show but hidden by default, peek on hover
- **Font**: Maple Mono NF (matches AwesomeWM)
- **Border radius**: 6px (matches AwesomeWM)

## Profile

Applied to: `~/.config/mozilla/firefox/umf19qex.default-release/chrome/`
