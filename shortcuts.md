# AwesomeWM Keyboard Shortcuts

Modkey = `Super` (Windows key)

## Launcher

| Keys                 | Action                      |
| -------------------- | --------------------------- |
| `Super + Return`     | Open terminal (kitty)       |
| `Super + p`          | Show menubar                |
| Left-click Arch logo | Rofi app launcher           |
| Right-click desktop  | Toggle main menu            |
| `Super + f`          | Open file explorer (Thunar) |
| `Super + b`          | Open browser (Firefox)      |
| `Super + Space`      | Rofi app launcher           |
| `Super + o`          | Open notes (Obsidian)       |

## Tags / Workspaces

| Keys                            | Action                            |
| ------------------------------- | --------------------------------- |
| `Super + 1-7`                   | View tag #1-7                     |
| `Super + Shift + 1-7`           | Toggle tag #1-7                   |
| `Super + Control + 1-7`         | Move focused window to tag #1-7   |
| `Super + Control + Shift + 1-7` | Toggle focused window on tag #1-7 |
| `Super + Left`                  | View previous tag                 |
| `Super + Right`                 | View next tag                     |
| `Super + Escape`                | Go back to previous tag           |

## Client / Windows

| Keys                       | Action                       |
| -------------------------- | ---------------------------- |
| `Super + Shift + j`        | Swap with next window        |
| `Super + Shift + k`        | Swap with previous window    |
| `Super + u`                | Jump to urgent window        |
| `Super + Tab`              | Go back (previous window)    |
| `Alt + f`                  | Toggle fullscreen            |
| `Super + x`                | Close window                 |
| `Super + n`                | Minimize window              |
| `Super + m`                | Toggle maximize              |
| `Super + Control + m`      | Toggle maximize vertically   |
| `Super + Shift + m`        | Toggle maximize horizontally |
| `Super + Control + space`  | Toggle floating              |
| `Super + Control + Return` | Move window to master        |
| `Super + Control + o`      | Move window to other screen  |
| `Super + t`                | Toggle keep on top           |
| `Super + Control + n`      | Restore minimized window     |
| `Super + d`                | Focus next window            |
| `Super + a`                | Focus previous window        |
| `Super + j`                | Focus next window            |
| `Super + k`                | Focus previous window        |

## Layout

| Keys                  | Action                 |
| --------------------- | ---------------------- |
| `Alt + space`         | Select next layout     |
| `Alt + Shift + space` | Select previous layout |

## Screen

| Keys                  | Action                |
| --------------------- | --------------------- |
| `Super + Control + j` | Focus next screen     |
| `Super + Control + k` | Focus previous screen |


## Awesome

| Keys                  | Action                |
| --------------------- | --------------------- |
| `Alt + F1`            | Show hotkeys help     |
| `Super + Control + r` | Reload awesome config |
| `Super + Shift + q`   | Quit awesome          |


## Mouse Bindings

| Action | Effect |
|--------|--------|
| Left-click window | Focus & raise |
| `Super + Left-drag` | Move window |
| `Super + Right-drag` | Resize window |
| Scroll on desktop | Next/previous tag |
| Scroll on volume widget | Volume up/down ±5% |
| Right-click volume widget | Toggle mute |
| Left-click volume widget | Volume slider popup |

## Bar Widgets

| Widget | Interaction |
|--------|-------------|
| Arch logo | Left-click: Rofi launcher |
| Taglist (1-7) | Left-click: view tag, `Super+click`: move window, Right-click: toggle, Scroll: switch tag |
| Tasklist icons | Left-click: focus/minimize, Right-click: client list menu, Scroll: cycle focus |
| Layout pill | Left-click: next layout, Right-click: prev layout, Scroll: switch layout |
| Clock | Textclock %H:%M |
